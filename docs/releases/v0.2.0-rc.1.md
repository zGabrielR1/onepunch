Primeira prévia 0.2.0 para testes. O nome OnePunch ainda é provisório.

## Novidades

- 27 exercícios e nove modelos de rotina, com sete exercícios em cada modelo.
- Modelos prontos com cópias editáveis, sem substituir rotinas e histórico existentes.
- Rascunhos locais recuperáveis; duplicação, arquivamento/restauração e proteção contra conflitos.
- Histórico por exercício, cargas/volume registrados e repetição de treino com séries desmarcadas.
- Ordem de exercícios e substituição de séries pendentes durante o treino, preservando as concluídas.
- Nome editável, progresso da sessão e revisão detalhada antes de finalizar.

## Downloads

- `onepunch-v0.2.0-rc.1-debug.apk`: Android 8+; APK de testes, assinado com certificado debug temporário do runner.
- `onepunch-v0.2.0-rc.1-linux-amd64.tar.gz`: API Linux + web + catálogo. Extraia, entre em `onepunch-linux-amd64/server` e execute `./onepunch-api`; abra `http://127.0.0.1:8097`.
- `verification.json`, `apk-signature.txt` e `SHA256SUMS.txt`: resultados de verificação, certificado e integridade dos arquivos deste commit.

## Verificação e limites

A publicação automatizada exige APK compilado e assinatura verificada, testes JVM,
testes Go com detector de corrida, testes de domínio web, bundle de produção e
fluxos de navegador aprovados. Consulte as contagens e o commit em `verification.json`.
Tudo roda no GitHub; nenhuma compilação nativa é feita no PC de desenvolvimento.

Interface Android em dispositivo físico/emulador ainda precisa da validação de
`docs/NATIVE_QA.md`. Não é uma versão de produção nem publicação na Play Store.

O certificado debug deste APK pode diferir de APKs anteriores. O Android pode
recusar atualização no lugar; não desinstale sua instalação com dados pessoais
para contornar isso. Use um dispositivo/perfil de teste separado. Não há migração
automática entre instalações assinadas por certificados diferentes.

A API é pessoal, sem autenticação pública; mantenha o endereço local. Reinicie
com o catálogo atualizado antes de sincronizar os exercícios novos. Modelos são
exemplos editáveis, não planos personalizados; ajuste ou remova exercícios.
