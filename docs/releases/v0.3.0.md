OnePunch 0.3.0 — backup e histórico pesquisável. Prévia para testes; o nome ainda é provisório.

## Novidades no Android

- Busque treinos concluídos por nome, exercício, equipamento ou nota, com busca sem distinção de acentos.
- Filtre o histórico pelos últimos 30/90 dias; totais e cargas registradas acompanham o filtro.
- Backup em JSON pelo seletor de arquivos do Android, incluindo rotinas, histórico, treino em andamento e rascunho.
- Importação com validação e prévia antes de confirmar. Treinos já salvos nunca são sobrescritos; conflitos de histórico bloqueiam a mesclagem.
- Seu treino em andamento e rascunho local têm prioridade. Rotinas com datas iguais e conteúdo diferente são mantidas como cópias, sem apagar a versão local.
- Uma cópia do estado anterior à importação fica disponível para exportação em Backup e dados. Não é um desfazer automático.
- Versão, tag, notas e metadados agora derivam de shared/release.properties; GitHub faz a compilação, os testes e a publicação.

## Como usar

No Histórico, use a busca e os filtros. No ícone Backup e dados, no topo da tela,
escolha Exportar backup ou um arquivo para restaurar. Confira a prévia e confirme
a mesclagem. O limite de arquivo é 8 MB; arquivos incompatíveis não alteram dados.
O backup contém dados pessoais em texto simples. Guarde-o com cuidado.

## Downloads e verificação

O APK debug para Android 8+, pacote Linux API/web, SHA256SUMS.txt e verification.json
são gerados do mesmo commit no GitHub, somente após todos os checks passarem.
verification.json informa contagens e vínculo com o run. Nenhuma compilação nativa
é feita no PC de desenvolvimento. Testes de interface Android e seletores de arquivo
em dispositivo real ainda precisam da validação de docs/NATIVE_QA.md.

O certificado debug temporário pode diferir de versões anteriores e impedir uma
atualização no lugar. Use dispositivo/perfil de teste; não desinstale um app com
dados pessoais para contornar assinatura. O backup novo só está disponível em
0.3.0; uma instalação anterior pode sincronizar rotinas e histórico concluído com
a API pessoal. Não há migração automática de treino ativo/rascunho entre assinaturas.

A API permanece pessoal e local, sem autenticação pública. Não há publicação na
Play Store nem alteração da visibilidade privada deste repositório.
