# Onepunch 1.0.0-rc.3

Web rest controls now support starting/restarting the selected exercise rest without completing a set, and shortening an active timer by 30 seconds. Zero-second rests disable manual start. Extending a timer just after its deadline uses the actual click time. Shortening to zero clears the timer.

Workout inputs, completed sets, history and routine templates are preserved. Timer deadlines continue to survive reloads. On narrow screens, timer controls wrap with accessible touch targets.

Version code 6; the application ID, owner signing certificate and version-1 data formats remain unchanged. Android product behavior is unchanged from RC.2.

This is a prerelease. Signed hosted run 42521634710 passed 77 JVM tests, 21 release-tooling tests, 17 web tests, four Go race tests and 226 browser workflow assertions, plus release identity and Linux-bundle smoke checks. Downloaded checksums passed; the 320px timer screenshot was reviewed. Exact-artifact physical-device QA remains pending. Independent signing-key backup and device QA remain required before stable promotion. No device installation is included.
