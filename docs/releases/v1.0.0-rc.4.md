# Onepunch 1.0.0-rc.4

Signed physical-device QA candidate, Android version code 7. Product behavior is unchanged from RC.3: native workout logging, recovery, backup/restore and sync; web manual rest controls and timer corrections.

The increased version code enables an RC.3-to-RC.4 signed update test using the same owner certificate and application ID. No data migration or fabricated history is added. Use a disposable test profile and preserve existing personal data.

Physical-device execution and findings are recorded separately from automated hosted checks. The checklist is in `docs/qa/RC4_DEVICE_QA.md`; the exact APK, source and certificate will be identified in `docs/qa/v1_0_0_rc_4.json` after the signed build. A successful build alone does not establish device QA. Stable promotion still requires full device coverage and independent owner signing-key backup confirmation.
